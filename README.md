# 3D

用 three.js 搭建的 3D 场景合集，每个场景一个文件夹。

在线浏览：https://yxengram.github.io/3D/

| 场景 | 说明 |
| --- | --- |
| [night-city](./night-city) | 夜幕下的繁华都市全景 + 雨夜霓虹小巷 |
| [reclaimed-street-corner](./reclaimed-street-corner) | 被自然收回的城市街角：三渲二风格的悬浮微缩场景，可自由旋转缩放，带昼夜切换 |
| [art-museum](./art-museum) | 艺术博物馆：建筑外观、大厅、现代绘画展厅三部分连通，可环视也可走进去；光影全部烘焙，对硬件要求很低 |

每个场景的运行方法见各自文件夹里的 README。
