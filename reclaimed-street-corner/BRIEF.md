# 用户原始需求（逐字）

用three.js制作一个「被自然收回的城市街角」微缩场景，以第三视角观察整个场景，整体像一个可以自由拖拽、旋转、缩放观看的微缩三维模型 / 小型景观，没有任何 UI 界面元素。地面为一个完整的正方形底座，所有元素都搭建在这个底座上，底座侧壁可见断裂的柏油路面剖面、裸露的混凝土与钢筋、以及从边缘垂落的盘结树根与藤蔓，构图紧凑、层次清晰，整体呈现出小巧、精致、可收藏的模型感。画面风格为三渲二，强调浓厚的日式二次元动画氛围，材质干净，轮廓明确，色彩以通透的翠绿、青苔绿与暖阳金黄为主调，辅以水泥灰白、锈红作为点缀与对比。场景主体是一处荒废多年的城市街角：一栋三四层高的混凝土楼房半塌，露出楼板断面与内部空间；一株巨大的老榕树自建筑中央破顶而出，树冠撑起整个场景的顶部，气根沿外墙垂落缠绕，把废墟和树木长成了一体。街角元素包括：爬满爬山虎与三角梅的外墙、断裂的天桥残段、歪斜的路灯与红绿灯（灯罩碎裂仍高悬）、锈蚀的公交站牌、玻璃碎裂并从内部长出杂草的自动贩卖机、被藤蔓吞没的报刊亭、倒地的立柱广告牌与熄灭的霓虹招牌残骸、生锈的自行车与堆叠轮胎、翻倒的路障、苔藓覆盖的石阶与花坛、被顶开的井盖、从地面裂缝涌出汇成小水潭的清澈溪流（潭边有鹅卵石、水生植物与几尾小鱼）、半埋入土中的旧汽车（车顶积土长出灌木与野花）、垂落的电线被藤蔓当作藤架、墙面残留褪色涂鸦与斑驳标语。街道不需要太大，但要有明确的街角转折感，像日式动画里常见的「废墟探险」一角。不要人物，但建筑内部一定要有足够内容，并且可以透过破碎的落地窗、坍塌的墙洞与楼板缺口清楚看到室内。
室内可见曾经的生活痕迹：倒塌的货架、锈蚀的冰柜、翻倒的桌椅、积灰的沙发与旧钢琴、坠落的吊灯、爬满苔藓的瓷砖地面、墙上歪斜的时钟与相框、角落的木箱与散落书页。室内地面积水成浅塘，波光反射到天花板上缓缓摇曳；阳光从屋顶破洞与叶隙灌入，形成数道清晰的丁达尔光柱，光柱中漂浮着细小尘埃与蒲公英绒毛；植物从窗口向室内蔓延，蕨类、苔藓与野花沿墙根铺开。要让废墟内部显得明亮、通透、生机勃勃，与外部浓密树荫下的清凉阴影形成鲜明的明暗层次，营造出「秘密基地」般的隐秘感与治愈感。美术风格重点强调：高精细建模、三渲二卡通渲染、清晰但柔和的轮廓线、细腻而简洁的材质层次（湿润苔藓、粗糙水泥、锈蚀金属、逆光下半透明的嫩叶、清澈水体）、强烈的透光感与体积光表现、暖金色阳光与青绿阴影的冷暖对比、地面与墙面上边缘锐利的斑驳光斑。整体气质应偏向安静、明亮、充满生命力，带一点文明退场后的怅然，但依然温柔而积极，像一幕被定格下来的日本动画午后街角场景模型。加入一些基础动效来增强生命力：树冠与藤蔓随微风轻摆、地面光斑随之摇曳晃动、光柱中尘埃与绒毛缓缓漂浮、水潭持续泛起细小涟漪与粼粼反光、小鱼游动、蝴蝶与蜻蜓在花丛间飞舞、偶有小鸟掠过并停在电线上、破布与残破窗帘随风飘动、叶尖与断檐偶尔滴落水珠、红绿灯极偶然地闪烁一次（残存电力的错觉）、远处有极淡的雾气缓慢流动。整体效果应像一个静止而精致的三维微缩世界，但带有恰到好处的细微动态，突出其三渲二、二次元、废墟、绿植、逆光通透、小巧精致的核心特征。
